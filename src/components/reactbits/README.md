# React Bits source

These free JavaScript + CSS component files are copied from the official React Bits repository (https://github.com/DavidHDev/react-bits) following https://reactbits.dev/get-started/installation. Components are locally editable source: SpotlightCard, CountUp, BlurText, AnimatedList, and TiltedCard.

The React Bits repository is MIT + Commons Clause licensed. Component-specific runtime packages used here are `motion`, `@hugeicons/react`, and `@hugeicons/core-free-icons`.
